# 发布前自检八问

写完逐条过，任何一条不过就回去改，不要「下次注意」。

1. **第一句是结论吗？** 第一句必须让人知道你做成了什么，而不是「本周我参与了…」。
2. **删掉一半，关键信息还在吗？** 还在就再删一半。
3. **有没有按工具分章？** 出现「AI 工具」「聊天软件」「项目管理平台」这类章节 = 失败。
4. **有没有把过程当成果？** 通篇找不到「看了/查了/聊了/配了」以外的内容 = 失败。
5. **有没有抢功？** 每条问一句：这是我做的，还是我推动的？动词对不对？
6. **有没有把待办写成已完成？** 状态词是不是只有那五个？未成稿的写没写「未成稿」？
7. **章节数和字数超了吗？** >5 章 或 >1200 字 = 不合格。
8. **下周计划是不是从本周推出来的？** 有没有出现「持续优化」「继续跟进」这种空条？

## 额外：如果这份周报要给不熟悉你项目的人看

再加两问：

9. 每个项目第一次出现时，有没有一句话说明「这是什么、为什么要做」？
10. 有没有一个外行看不懂的缩写、代号、内部黑话？有就展开或删掉。
